# CGSim Visualization

A Streamlit web application for visualizing CGSim output data in real time. Live database updates can be paused, allowing the user to step forward and backward through events. If the user navigates to a specific site or CPU page, the user can step forward through events specifically for that site or CPU.

## Repository Location
This repository is located in the `CGSim_Visualization` directory of the [CGSim](https://github.com/REDWOOD24/CGSim) repository. Default configuration paths are set up for running the application from this location.

## Installation

1. **Navigate to this directory:**
   ```bash
   cd CGSim_Visualization
   ```

2. **Install Python dependencies:**
   The app has three requirements: streamlit, pandas, and plotly. These can be installed with:
   ```bash
   pip install -r requirements.txt
   ```
   It is recommended to do this in a new (or the user's preferred) python environment.

## Running the Application

From the `CGSim_Visualization` directory, run:

```bash
streamlit run CGSim_Visualization.py
```

The application will open in your default web browser (typically at `http://localhost:8501`).

## Configuration

The application needs two configuration inputs:

1. **Output Database** - The SQLite database file generated by the CGSim simulation (e.g., `output.db`)
2. **Site Configuration File** - A JSON file containing site information (e.g., `site_info.json`)

### Configuring via the Web Interface

1. Open the application and navigate to the **Configuration** page (accessible from the sidebar)
2. **Output Database Configuration:**
   - Enter the path to your output directory (e.g., `../output`)
   - Enter the database filename (default: `output.db`)
   - Press Enter to apply changes
3. **Site Configuration Files:**
   - Enter the path to your config-files directory (e.g., `../config-files`)
   - Press Enter to scan the directory
   - Select your desired configuration file from the dropdown
4. **Save Configuration:**
   - Click the "Save Configuration" button to persist your settings

### Configuration Persistence

The application uses two mechanisms for configuration:

1. **Session State** - Configuration changes are immediately applied to the current browser session. When you select a different config file or change paths, all pages will use the updated values without needing to save. However, these changes are lost when you close the browser or restart the Streamlit server.

2. **vis_config.json** - Clicking "Save Configuration" writes your settings to a `vis_config.json` file in the `CGSim_Visualization` directory. This file is automatically loaded when the application starts, so your configuration persists across sessions.

The `vis_config.json` file contains:
```json
{
    "output_dir": "../output",
    "output_filename": "output.db",
    "config_dir": "../config-files",
    "selected_config_file": "site_info.json"
}
```

### Default Paths

If `vis_config.json` does not exist or cannot be read, the application defaults to:
- Output directory: `../output`
- Output filename: `output.db`
- Config directory: `../config-files`
- Selected config file: `site_info.json`

## Pages

- **CGSim_Visualization** - Shows overall job status across all sites with a pie chart and site summary table
- **Site** - Detailed view of a specific site with CPU grid visualization and job metrics
- **CPU** - Individual CPU job history and events
- **Failed Jobs** - Analysis of failed jobs by site
- **Configuration** - Configure database and config file paths

## Time Navigation

The application includes time navigation controls in the sidebar:
- **Play/Pause** - Toggle between live updates and paused state
- **Slider** - Jump to a specific timestep
- **Step Back/Forward** - Navigate through timesteps one at a time
- **Dropdown** - Select a specific timestep from available options
